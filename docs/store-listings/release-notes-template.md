# Release Notes Template — Success Muslim

Use one of these templates for each release. Keep under **500 chars** for Play and **4,000 chars** for App Store.

## Major release template

```
Version X.Y — [Theme name]

✦ NEW
• [Feature 1, user-benefit phrasing]
• [Feature 2]

✦ IMPROVED
• [Improvement 1]
• [Improvement 2]

✦ FIXED
• [Bug fix 1]
• [Bug fix 2]

Jazakum Allahu khayran for the support! Send feedback to support@successmuslim.app.
```

## Minor / patch release template

```
Version X.Y.Z
• [Short summary of fix or small improvement]
• [Stability and performance improvements]

Thank you for using Success Muslim. Feedback: support@successmuslim.app
```

## Ramadan / Eid special release template

```
Ramadan Mubarak from Success Muslim! 🌙

• Ramadan-optimized dashboard
• Tarawih and Qiyam tracking
• Daily fasting checklist
• Ramadan Optimizer planner
• Special daily duas and reminders

May Allah accept all our worship this blessed month.
```

## Style rules

- Lead with user benefit, not technical jargon.
- Use Islamic salutations sparingly and authentically.
- No emoji on iOS release notes if it pushes the line over 4,000 chars; emojis are fine on Play.
- Never reference internal tickets, code names, or competitor apps.
- Always end with the support email.

## Localization

Translate release notes for each supported locale before submitting:
- en-US (default)
- ms-MY
