QUICK TOUR
1. Sign in → Home dashboard.
2. Bottom nav has 7 tabs: Home, Iman, Health, Wealth, Productivity, Family, Settings.
3. Iman → Prayer Times shows today's prayers with adhan toggle.
4. Iman → Quran opens the bundled Uthmani Mushaf.
5. Health → IF Timer starts an intermittent fasting session.
6. Family → Sample Family is pre-joined.

PERMISSIONS
• Location (optional): only to compute accurate prayer times. Manual zone selection is always available.
• Notifications (POST_NOTIFICATIONS, API 33+): local prayer reminders only.
• No background location, no contacts, no SMS, no calendar, no camera, no microphone, no storage permissions.
